# Rahul Kumar — Data Analyst Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript to showcase Rahul Kumar's entry-level Data Analyst projects, technical skills and professional contact information.

## Featured Projects

1. GeoInsights — Regional Sales Analytics & BI Dashboard
2. MarketLens — Consumer Spending & Engagement Analytics
3. RetailPulse — Customer Analytics & Relational SQL Pipeline
4. Dining Demand & Revenue Optimizer — Restaurant Analytics Dashboard

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

Open `index.html` in a browser, or use VS Code with the Live Server extension.

## Deployment

This project is designed for GitHub Pages. After uploading the assets, enable Pages from the repository's **Settings → Pages** and select the `main` branch with the `/ (root)` folder.
